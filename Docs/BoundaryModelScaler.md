# BoundaryModelScaler.cs

掛在 SampleScene 的美援2F（5_5）模型上。Boundary 引用 VR Walking Boundary。

| 行 | 說明 |
| ---: | --- |
| 1 | 匯入 Unity 的元件、Transform 和向量型別。 |
| 3–5 | 限制同一模型只掛一份。執行順序 100 讓模型在邊界更新尺寸後才讀取資料。 |
| 7–9 | 指定邊界控制器，並決定是否跟著降低模型高度。 |
| 11–16 | 保存縮放用父物件及模型原本的父物件、位置、旋轉、縮放和排列順序。 |
| 18–24 | 每幀檢查邊界是否可用。若不可用就還原模型。 |
| 26–28 | 讀取當前中心、旋轉和尺寸。第一次建立縮放父物件。 |
| 30 | 將目前的寬、長各除以編輯時的寬、長。 |
| 31–33 | 讓父物件跟隨當前區域，依邊界座標的 X、Z 軸縮放。選擇縮高度時使用兩個倍率中較小的值。 |
| 36–46 | 記錄原始變換，以邊界物件為父層建立新的縮放容器。用世界變換保留原本的位置和角度，然後把模型放入容器。 |
| 49–52 | 停用元件時呼叫還原。 |
| 54–66 | 把模型移回原父層，還原變換和排列，最後銷毀暫時的縮放容器。 |

例如 Straight 寬 2 公尺、長 7 公尺，縮到長 5 公尺時，X 倍率為 1，Z 倍率為 5/7。模型原本的旋轉與偏移一起在邊界座標系中套用這個變換，所以起始時貼邊的部分在收縮時仍跟同一條邊移動。預設只縮地面範圍。Spot Light 和頭顯不隸屬於模型，因此不會被模型縮放。
